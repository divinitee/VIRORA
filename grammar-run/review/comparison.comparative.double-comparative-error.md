## transform (15)

1. _This sentence marks the comparative twice. Write the correct comparative._  
   This **watch** is more cheaper than the one **in the window**.  
   → This **watch** is ______ than the one **in the window**.  
   key: cheaper  
   why: Cheap is a short adjective: cheaper. More cheaper marks the comparative twice.

2. _This sentence marks the comparative twice. Write the correct comparative._  
   My **brother** is more older than me, but I am **faster**.  
   → My **brother** is ______ than me, but I am **faster**.  
   key: older  
   why: Old is a short adjective: older. More older marks the comparative twice.

3. _This sentence marks the comparative twice. Write the correct comparative._  
   The exam was more easier than the **homework**, **Dad**.  
   → The exam was ______ than the **homework**, **Dad**.  
   key: easier  
   why: Easy becomes easier. It already has -er, so more is not needed.

4. _This sentence marks the comparative twice. Write the correct comparative._  
   This sofa is more comfortabler than the **old one** in the **kitchen**.  
   → This sofa is ______ than the **old one** in the **kitchen**.  
   key: more comfortable  
   why: Comfortable is a long adjective: more comfortable. Do not add -er as well.

5. _This sentence marks the comparative twice. Write the correct comparative._  
   Your idea is more better than mine, **Olga**. Let's **start now**.  
   → Your idea is ______ than mine, **Olga**. Let's **start now**.  
   key: better  
   why: Better is already the comparative of good, so more is not needed.
