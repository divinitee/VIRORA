## transform (15)

1. _Rewrite the sentence with the long adjective in brackets. Keep the meaning._  
   A bus ticket to **Namangan** is cheaper than a **train** ticket.  
   → A **train** ticket to **Namangan** is ______ (expensive) than a bus ticket.  
   key: more expensive  
   why: Cheap takes -er, but expensive is a long adjective, so it takes more: more expensive.

2. _Rewrite the sentence with the long adjective in brackets. Keep the meaning._  
   For me, **history** is easier than **physics**.  
   → For me, **physics** is ______ (difficult) than **history**.  
   key: more difficult  
   why: Easy takes -ier, but difficult is a long adjective, so it takes more: more difficult.

3. _Rewrite the sentence with the long adjective in brackets. Keep the meaning._  
   For **children**, the park is safer than the main road.

   key: more dangerous  
   why: Safe takes -r, but dangerous is a long adjective, so it takes more: more dangerous.
