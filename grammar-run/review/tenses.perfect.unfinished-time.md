# tenses.perfect.unfinished-time — review sample (B1)

Each item shows one random filler combination (in bold). Mark anything a teacher wouldn't accept.

## choose (20)

1. So far **this week**, I ______ **two** emails to my teacher.  
   options: ✔ have sent · sent · had sent · send  
   why: "So far" + this period is not over: have sent.

2. So far today, my father ______ **three** cups of **tea**.  
   options: drank · had drunk · drinks · ✔ has drunk  
   why: "So far today": the day goes on: has drunk.

   options: had read · will read · ✔ have read · read  
   why: "So far" means up to now: have read.

## create (8)

1. Write one sentence about what you have done so far today.  
   must use: so far today + present perfect · exactly one sentence · so far · have / has + past participle

2. Write one sentence about how many cups of tea or coffee you have had this week.  
   must use: have had … this week · exactly one sentence · present perfect · this week

3. Write one sentence about the weather so far this month.  
   must use: it has been / it has rained · exactly one sentence · so far this month · present perfect

4. Write one sentence with haven't … yet today.  
   must use: haven't + past participle + today · exactly one sentence · haven't · today

5. Write one sentence about how many books or films you have finished this year.  
   must use: have read / have watched this year · exactly one sentence · this year · a number

6. Write one sentence about a family member's day so far.  
   must use: has + past participle so far · exactly one sentence · he / she has · so far

7. Write one sentence about this morning when it is already evening.  
   must use: past simple for a finished morning · exactly one sentence · past simple · this morning

8. Write two sentences: one about this week (not finished) and one about last week (finished).  
   must use: present perfect vs past simple · exactly two sentences · present perfect with this week · past simple with last week

## express (5)

1. Describe your week so far. What have you done, and what haven't you done yet? Write three or four sentences.  
   target: present perfect for this week · look for: so far / this week · have + past participle · haven't … yet

2. Write about your English this year: what you have learned and read so far. Write three or four sentences.  
   target: present perfect for this year · look for: so far this year · at least two verbs · a number

3. Describe a busy day that is not finished yet. Write three or four sentences.  
   target: present perfect for today · look for: so far today · has / have · still to do

4. Write a message to a friend about a trip you are still on. What have you seen so far? Write three or four sentences.  
   target: present perfect on a trip · look for: so far · have seen / visited · a place

5. Compare this month with last month. Write three or four sentences.  
   target: present perfect vs past simple · look for: this month + present perfect · last month + past simple · three or four sentences
