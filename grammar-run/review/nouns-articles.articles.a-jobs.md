## create (8)

1. Write one sentence about the job of someone in your family.  
   must use: a/an + job · exactly one sentence · must use is a or is an

2. What do you want to be? Write one sentence.  
   must use: want to be a/an · exactly one sentence · must use want to be a or want to be an

3. Write one sentence about an engineer, an artist or an actor you know.  
   must use: an + job · exactly one sentence · must use an

4. Write one sentence about two people with the same job.  
   must use: plural job, no article · exactly one sentence · must use are · plural job

5. Write one sentence about your teacher.  
   must use: a/an + job · exactly one sentence · must use a or an

6. Write one sentence with an adjective before a job, like an old farmer.  
   must use: a/an + adjective + job · exactly one sentence · must use a or an · adjective before the job

7. Ask a friend about their mother's job. Write one question and the answer.  
   must use: a/an + job · exactly two sentences · must use a or an

8. Write two sentences: one with a + job and one with an + job.  
   must use: a / an + job · exactly two sentences · must use a · must use an
