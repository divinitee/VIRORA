## transform (15)

1. _Make a yes/no question._  
   Your brother is at the **market**, **Aziz**.

   key: Is  
   why: There is no main verb here, only be, so the question starts with Is. Don't add do.

   key: Are  
   why: There is no main verb here, only be, so the question starts with Are. Don't add do.

   key: Is  
   why: There is no main verb here, only be, so the question starts with Is. Don't add do.

6. _Make a yes/no question. Write one word in each gap._  
   Your sister plays **tennis** on **Tuesday**.  
   → ______ your sister ______ **tennis** on **Tuesday**?  
   key: Does + play  
   why: Plays is a main verb, so use Does with she, and the verb goes back to play.

7. _Make a yes/no question. Write one word in each gap._  
   You live near the **bazaar**, **Olga**.  
   → ______ you ______ near the **bazaar**, **Olga**?  
   key: Do + live  
   why: Live is a main verb, so use Do with you, then the base verb live.

8. _Make a yes/no question. Write one word in each gap._  
   Your dad has a **car**, **Malika**.  
   → ______ your dad ______ a **car**, **Malika**?  
   key: Does + have  
   why: Has is a main verb here, so use Does with he, and has goes back to have.

9. _Make a yes/no question. Write one word in each gap._  
   Your cousins work in **Bukhara**, **Malika**.  
   → ______ your cousins ______ in **Bukhara**, **Malika**?  
   key: Do + work
