## transform (15)

1. _Join the two sentences with so that._  
   I wrote the **date** down. I didn't want to forget it, **Timur**.  
   → I wrote the **date** down ______ I wouldn't forget it, **Timur**.  
   key: so that (also: so, in order that)  
   why: didn't want to forget → so that I wouldn't forget.

2. _Join the two sentences with so that._  
   Mum cooked a lot. She wanted everyone to have enough **plov**, **Olga**.  
   → Mum cooked a lot ______ everyone would have enough **plov**, **Olga**.  
   key: so that (also: so, in order that)  
   why: wanted everyone to have → so that everyone would have.

3. _Join the two sentences with so that._  
   Speak clearly. Then the **guests** can understand you, **Aziz**.  
   → Speak clearly ______ the **guests** can understand you, **Aziz**.  
   key: so that (also: so, in order that)  
   why: Then … can understand → so that.

4. _Join the two sentences with so that._  
   We left early. We wanted a good seat at the **match**, **Timur**.  
   → We left early ______ we could get a good seat at the **match**, **Timur**.  
   key: so that (also: so, in order that)  
   why: wanted a good seat → so that we could get.

5. _Join the two sentences with so that._  
   Take a map. Then you won't get lost in **Khiva**, **Olga**.  
   → Take a map ______ you won't get lost in **Khiva**, **Olga**.  
   key: so that (also: so, in order that)  
   why: Then you won't get lost → so that.

6. _Correct the mistake._  
   I went out for buy some **fruit**, **Aziz**.  
   → I went out ______ buy some **fruit**, **Aziz**.  
   key: to (also: in order to)  
   why: Purpose + verb: to buy, not for buy.

7. _Correct the mistake._  
   She came here for to see her **cousins**, **Timur**.  
   → She came here ______ see her **cousins**, **Timur**.  
   key: to (also: in order to)  
   why: Purpose + verb: to see, not for to see.

8. _Correct the mistake._  
   I set an alarm in order to I wouldn't be late **for work**, **Aziz**.  
   → I set an alarm ______ I wouldn't be late **for work**, **Aziz**.  
   key: so that (also: so, in order that)  
   why: in order to needs a verb, not a clause: so that.

9. _Correct the mistake._  
   Close the door for the **kitten** can't get out, **Olga**.  
   → Close the door ______ the **kitten** can't get out, **Olga**.  
   key: so that (also: so, in order that)

10. _Correct the mistake._

   → We spoke quietly ______ the **grandparents** could sleep, **Timur**.  
   key: so that (also: so, in order that)  
   why: because of needs a noun, not a clause: so that.

## create (8)

1. Write one sentence about why you are learning English. Use so that.  
   must use: I'm learning English so that I can … · exactly one sentence · so that + subject + can · a present verb

2. Write one sentence about something you did yesterday so that you wouldn't be late.  
   must use: I … so that I wouldn't be late. · exactly one sentence · so that + wouldn't · a past verb

3. Write one sentence giving advice to a friend. Use so that.  
   must use: Take … so that you don't … · exactly one sentence · an imperative · so that + clause

4. Write one sentence about why you went to a shop. Use to + verb.  
   must use: I went to the … to buy … · exactly one sentence · to + verb · no for + verb

5. Write one sentence about why your family saves money.  
   must use: We save money so that we can … · exactly one sentence · so that + can · a present verb

6. Write one sentence about something a parent did for you when you were small.  
   must use: My mum … so that I could … · exactly one sentence · so that + could · a past verb

7. Write one sentence about how you study for an exam.  
   must use: I … so that I can remember … · exactly one sentence · so that · no in order to + subject

8. Write two sentences: one with to + verb and one with so that + clause.  
   must use: I went … to … / I left early so that … · exactly two sentences · to + verb · so that + subject + verb
