## transform (15)

1. _Make the request more polite. Use would like._  
   I want to see the **room** **now**.  
   → I ______ (see) the **room** **now**, please.  
   key: would like to see (also: 'd like to see)  
   why: Would like is the polite way to say want. It is followed by to + base verb: would like to see.

2. _Make the request more polite. Use would like._  
   We want to change our **room** **today**.  
   → We ______ (change) our **room** **today**, please.  
   key: would like to change (also: 'd like to change)  
   why: Use would like + to + base verb for a polite request: would like to change.

3. _Make the request more polite. Use would like._  
   I want to ask a question about the **homework**, **Ms Petrova**.  
   → I ______ (ask) a question about the **homework**, **Ms Petrova**.  
   key: would like to ask (also: 'd like to ask)  
   why: Would like + to + base verb is polite: would like to ask.

4. _Make the request more polite. Use would like._  
   My mother wants to speak with the **manager** **this morning**.  
   → My mother ______ (speak) with the **manager** **this morning**, please.  
   key: would like to speak (also: 'd like to speak)  
   why: With he or she, would like stays the same (never would likes). Then to speak.

5. _Make the request more polite. Use would like._  
   I want to buy **three** tickets for **the show**.  
   → I ______ (buy) **three** tickets for **the show**, please.  
   key: would like to buy (also: 'd like to buy)  
   why: Would like + to + base verb is the polite form: would like to buy.

6. _Turn this into a polite invitation with Would you like … ?_  
   Do you want to dance?  
   → ______ (dance) with **us** **at the wedding**?  
   key: would you like to dance  
   why: A polite invitation is Would you like + to + base verb.

7. _Turn this into a polite invitation with Would you like … ?_  
   Bobur, do you want to play **cards**?  
   → ______ (play) **cards** with us after **lunch**, Bobur?  
   key: would you like to play  
   why: Invite with Would you like + to + base verb: Would you like to play…?

## express (5)

1. You are at a restaurant with your family. Write a short dialogue with the waiter: order food, drinks and ask for the bill.  
   target: would like to + verb for polite requests · look for: I'd like to … / We'd like to … · Would you like to … ? from the waiter · to + base verb after like

2. Write a message inviting a friend to your birthday party. Say what you would like to do together.  
   target: Would you like to … ? and we'd like to … · look for: Would you like to + verb · two or more different verbs after would like to · a day or time

3. Describe your dream holiday. Where would you like to go, and what would you like to do there? Write three or four sentences.  
   target: would like to + base verb · look for: would like to go / visit / see · a place name · no -ing or bare verb after would like

4. What would you like to do after you finish school or university? What would your parents like you to do? Write three or four sentences.  
   target: would like to + verb and would like + person + to + verb · look for: I'd like to … · would like me to … · no would like that …

5. You call a language centre. Write what you say: ask for information about a course and book a place.  
   target: polite requests with would like to · look for: I'd like to know / ask / book · please · to + base verb after like
