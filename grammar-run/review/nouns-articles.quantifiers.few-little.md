## transform (15)

1. _Say it is only a small number or amount. Write a few or a little._  
   There is some milk in the **bottle**, **Timur**.  
   → There is ______ milk in the **bottle**, **Timur**.  
   key: a little  
   why: The noun is uncountable, so use a little.

2. _Say it is only a small number or amount. Write a few or a little._  
   There are some people at the **bus stop**, **Olga**.  
   → There are ______ people at the **bus stop**, **Olga**.  
   key: a few  
   why: The noun is countable and plural, so use a few.

3. _Say it is only a small number or amount. Write a few or a little._  
   We have some bread for **lunch**, **Aziz**.  
   → We have ______ bread for **lunch**, **Aziz**.  
   key: a little  
   why: The noun is uncountable, so use a little.

4. _Say it is only a small number or amount. Write a few or a little._

   key: a few  
   why: The noun is countable and plural, so use a few.

5. _Say it is only a small number or amount. Write a few or a little._

   → There is ______ money in my **wallet**, **Olga**.  
   key: a little

6. _Use the new noun. Write a few or a little._  
   I have some coins in my **jacket**, **Aziz**.  
   → I have ______ money in my **jacket**, **Aziz**.  
   key: a little  
   why: Money is uncountable (coins are countable), so use a little.

7. _Use the new noun. Write a few or a little._  
   There is some bread in the **bag**, **Timur**.  
   → There are ______ buns in the **bag**, **Timur**.  
   key: a few  
   why: Buns are countable and plural (bread is not), so use a few.

8. _Use the new noun. Write a few or a little._  
   **Olga** gave me some tips for the **exam**.  
   → **Olga** gave me ______ advice for the **exam**.  
   key: a little  
   why: Advice is uncountable (tips are countable), so use a little.

9. _Use the new noun. Write a few or a little._  
   We bought some fruit at the **supermarket** in **Bukhara**.  
   → We bought ______ apples at the **supermarket** in **Bukhara**.  
   key: a few  
   why: Apples are countable and plural (fruit here is not), so use a few.

10. _Use the new noun. Write a few or a little._  
   I have some homework for **science**, **Timur**.  
   → I have ______ exercises for **science**, **Timur**.  
   key: a few  
   why: Exercises are countable and plural (homework is not), so use a few.

11. _Say it is only a small number or amount of each. Write a few or a little in each gap._

   → We have ______ eggs and ______ butter for the **pancakes**, **Aziz**.

   why: eggs: countable plural noun → a few; butter: uncountable noun → a little.

   key: a little + a few
