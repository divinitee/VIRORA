## transform (15)

1. _The first sentence has a mistake with a/an. Complete the correct sentence with one word._  
   Can you give me an information about the **hotel**, **Malika**?  
   → Can you give me ______ information about the **hotel**, **Malika**?  
   key: some  
   why: Information is uncountable, so use some, not a/an.

2. _The first sentence has a mistake with a/an. Complete the correct sentence with one word._  
   I have a news about **the exam**, **Malika**.  
   → I have ______ news about **the exam**, **Malika**.  
   key: some  
   why: News is uncountable, so use some, not a/an.

3. _The first sentence has a mistake with a/an. Complete the correct sentence with one word._  
   There is a luggage in the **corridor**, **Timur**.  
   → There is ______ luggage in the **corridor**, **Timur**.  
   key: some  
   why: Luggage is uncountable, so use some, not a/an.

4. _The first sentence has a mistake with a/an. Complete the correct sentence with one word._  
   We bought an equipment for the **music room**, **Timur**.  
   → We bought ______ equipment for the **music room**, **Timur**.  
   key: some  
   why: Equipment is uncountable, so use some, not a/an.

5. _The first sentence has a mistake with a/an. Complete the correct sentence with one word._  
   **Aziz** has a work to do in **Bukhara**.  
   → **Aziz** has ______ work to do in **Bukhara**.  
   key: some  
   why: Work is uncountable, so use some, not a/an.

6. _The first sentence has a mistake. Complete the correct sentence with one word._  
   The guide gave us many informations about **Bukhara**, **Aziz**.  
   → The guide gave us a lot of ______ about **Bukhara**, **Aziz**.  
   key: information  
   why: Information is uncountable, so it never takes -s.

7. _The first sentence has a mistake. Complete the correct sentence with one word._  
   We heard many newses from **Bukhara**, **Timur**.  
   → We heard a lot of ______ from **Bukhara**, **Timur**.  
   key: news  
   why: News is uncountable. It already ends in s, but it is not a plural.

8. _The first sentence has a mistake. Complete the correct sentence with one word._  
   **Timur** took many luggages to **Bukhara**.  
   → **Timur** took a lot of ______ to **Bukhara**.  
   key: luggage  
   why: Luggage is uncountable, so it never takes -s.

9. _The first sentence has a mistake. Complete the correct sentence with one word._  
   The **sports hall** has many new equipments, **Aziz**.  
   → The **sports hall** has a lot of new ______, **Aziz**.  
   key: equipment  
   why: Equipment is uncountable, so it never takes -s.

10. _The first sentence has a mistake. Complete the correct sentence with one word._  
   My teacher has many knowledges about **science**, **Timur**.  
   → My teacher has a lot of ______ about **science**, **Timur**.  
   key: knowledge  
   why: Knowledge is uncountable, so it never takes -s.

11. _Say the same thing with the uncountable noun. Complete the sentence with one word._  
   We have three suitcases for the trip to **Bukhara**, **Aziz**.  
   → We have ______ luggage for the trip to **Bukhara**, **Aziz**.  
   key: some  
   why: Suitcase is countable, but luggage is uncountable, so use some luggage.

12. _Say the same thing with the uncountable noun. Complete the sentence with one word._  
   The gym has new balls and nets, **Malika**.  
   → The gym has ______ new equipment, **Malika**.  
   key: some  
   why: Balls and nets are countable, but equipment is uncountable, so use some.

13. _Say the same thing with the uncountable noun. Complete the sentence with one word._  
   I have two facts about the **old town** in **Termez**.  
   → I have ______ information about the **old town** in **Termez**.  
   key: some  
   why: Fact is countable, but information is uncountable, so use some.

14. _Say the same thing with the uncountable noun. Complete the sentence with one word._  
   **Timur** has two tasks for the **party**.  
   → **Timur** has ______ work for the **party**.  
   key: some  
   why: Task is countable, but work (meaning things to do) is uncountable, so use some.

15. _Say the same thing with the uncountable noun. Complete the sentence with one word._  
   I have two messages from **Samarkand**, **Malika**.  
   → I have ______ news from **Samarkand**, **Malika**.  
   key: some  
   why: Message is countable, but news is uncountable, so use some.
