## transform (15)

1. _Rewrite the sentence about the new person. Keep want + to._  
   I want to buy **a cake** for my **best friend**.  
   → My sister ______ (buy) **a cake** for her **best friend**.  
   key: wants to buy  
   why: My sister is one person, so want becomes wants. The second verb stays to + base: to buy.

2. _Rewrite the sentence about the new person. Keep want + to._  
   We want to visit **the old city** on **Saturday**.  
   → Timur ______ (visit) **the old city** on **Saturday**.  
   key: wants to visit  
   why: Timur is one person, so use wants, then to + base verb: to visit, not to visits.

3. _Rewrite the sentence about the new person. Keep want + to._  
   They want to learn **to drive** in the **spring**.  
   → Our neighbour ______ (learn) **to drive** in the **spring**.  
   key: wants to learn  
   why: Our neighbour is one person, so use wants + to learn.

4. _Rewrite the sentence about the new person. Keep want + to._  
   I want to finish my **homework** before **nine**.  
   → Aziz ______ (finish) his **homework** before **nine**.  
   key: wants to finish  
   why: Aziz is one person, so want becomes wants. Finish stays in the base form after to.

5. _Rewrite the sentence about the new person. Keep want + to._  
   You want to watch **a film** tonight.  
   → Grandpa ______ (watch) **a film** tonight.  
   key: wants to watch  
   why: Grandpa is one person, so use wants, then to watch.

6. _Rewrite the sentence in the negative._  
   Lola wants to live in **another city** **this year**.  
   → Lola ______ (live) in **another city** **this year**.  
   key: doesn't want to live  
   why: Lola is one person, so the negative is doesn't want. Want loses its -s after doesn't, and to live stays.

7. _Rewrite the sentence in the negative._  
   I want to eat **bread** **today**.  
   → I ______ (eat) **bread** **today**.  
   key: don't want to eat  
   why: With I, the negative is don't want, still followed by to + base verb.

8. _Rewrite the sentence in the negative._  
   My friends want to play **computer games** **at my house**.  
   → My friends ______ (play) **computer games** **at my house**.  
   key: don't want to play  
   why: My friends is plural, so the negative is don't want + to play.

9. _Rewrite the sentence in the negative._  
   Bekzod wants to sit near **the window** in **maths**.  
   → Bekzod ______ (sit) near **the window** in **maths**.  
   key: doesn't want to sit  
   why: Bekzod is one person, so use doesn't want + to sit. Never doesn't wants.

10. _Rewrite the sentence in the negative._  
   We want to spend our **birthday money** on **games**.  
   → We ______ (spend) our **birthday money** on **games**.  
   key: don't want to spend  
   why: With we, the negative is don't want, then to + base verb: to spend.

11. _Rewrite the request with want + person + to + verb._  
   Mum says to me: "Wash the **carpet** **after dinner**, please."  
   → Mum wants ______ (wash) the **carpet** **after dinner**.  
   key: me to wash  
   why: Mum is talking to me, so use want + me + to + verb. Not "wants that I wash".

12. _Rewrite the request with want + person + to + verb._  
   The doctor says to my grandfather: "Walk every **morning**."  
   → The doctor wants my grandfather ______ (walk) every **morning**.  
   key: to walk  
   why: After want + person, use to + base verb: wants my grandfather to walk.

13. _Rewrite the request with want + person + to + verb._  
   Our teacher says to us: "Bring your **dictionaries** **on Friday**."  
   → Our teacher wants ______ (bring) our **dictionaries** **on Friday**.  
   key: us to bring  
   why: The teacher is talking to us, so use wants + us + to bring.

14. _Rewrite the request with want + person + to + verb._  
   Dad says to my brother: "Turn off the **music** **at ten**."  
   → Dad wants ______ (turn) off the **music** **at ten**.  
   key: my brother to turn (also: him to turn)  
   why: Use want + person + to + verb: wants my brother to turn. Not "wants that my brother turns".

15. _Rewrite the request with want + person + to + verb._  
   I say to you: "Help me with my **project** on **Saturday**."  
   → I want ______ (help) me with my **project** on **Saturday**.  
   key: you to help  
   why: Use want + you + to + verb: I want you to help me.

## create (8)

1. Write one sentence about a job you want to do in the future.  
   must use: want to + base verb · exactly one sentence · must use I want to · must name a job

2. Write one sentence about a place you want to visit and say when.  
   must use: want to visit · exactly one sentence · must name a place · must include a time

3. Write one sentence about something you don't want to do this weekend.  
   must use: don't want to + base verb · exactly one sentence · must use don't want to · must include this weekend

4. Write one sentence about something a family member wants to do.  
   must use: wants to + base verb · exactly one sentence · must name a family member · must use wants to

5. Write one sentence about something your parents or teacher want you to do.  
   must use: want + me + to + base verb · exactly one sentence · must use want(s) me to · must not use that after want

6. Write a question to ask a friend what they want to do after school.  
   must use: Do you want to … ? or What do you want to … ? · exactly one question · must end with a question mark · must use want to

7. Write one sentence about a skill you want to learn this year.  
   must use: want to learn · exactly one sentence · must name a skill · must include this year

8. Write two sentences: one thing you want to buy, and one thing you don't want to buy.  
   must use: want to buy and don't want to buy · exactly two sentences · one positive, one negative · must use to buy in both

## express (5)

1. Talk about your plans for the next five years. What do you want to do, and what don't you want to do? Write three or four sentences.  
   target: want to / don't want to + base verb · look for: want to + base verb · don't want to + base verb · no bare verb or -ing after want

2. Your friend asks: "What do you want to do this weekend?" Answer and give reasons. Write three or four sentences.  
   target: want to + base verb for plans · look for: want to + base verb · a reason with because · a time like this weekend or on Saturday

3. What do your parents want you to do in the future? Do you want the same thing? Write three or four sentences.  
   target: want + person + to + base verb · look for: want(s) me to + base verb · I want to / I don't want to · no want that…

4. Describe a trip you want to take. Where do you want to go and what do you want to see there? Write three or four sentences.  
   target: want to + base verb · look for: want to go / visit / see · a place name · two or more different verbs after want to

5. Write a short message to a friend inviting them to do something with you. Say what you want to do and what you want them to bring.  
   target: want to + verb and want + you + to + verb · look for: want to + base verb · want you to + base verb · a day or time
