   must use: The bus that I take … · exactly one sentence · that or which · a time word

6. Write one sentence about a song that makes you happy.  
   must use: … is a song that makes me … · exactly one sentence · that makes · a feeling word

   must use: I lost the … that … · exactly one sentence · that or which · a past verb

   must use: … that … / … which … · exactly two sentences · that once · which once
