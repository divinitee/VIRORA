## transform (15)

1. _Say the same thing with a superlative._  
   No **cafe** in town is better than this one, **Olga**.  
   → This is ______ ______ **cafe** in town, **Olga**.  
   key: the + best  
   why: If nothing is better, this one is the best. Good, better, the best.

2. _Say the same thing with a superlative._  
   **Dad**, no day of the week is worse than **Monday** for me.  
   → **Dad**, **Monday** is ______ ______ day of the week for me.  
   key: the + worst  
   why: If no day is worse, this day is the worst. Bad, worse, the worst.

3. _Say the same thing with a superlative._  
   Nobody in our **school** is better at **chess** than Lola.  
   → Lola is ______ ______ in our **school** at **chess**.  
   key: the + best  
   why: If nobody is better, Lola is the best. Good, better, the best.

4. _Say the same thing with a superlative._  
   No film this **summer** was worse than this one, **Olga**.  
   → This was ______ ______ film this **summer**, **Olga**.  
   key: the + worst  
   why: If no film was worse, this one was the worst. Bad, worse, the worst.

5. _Say the same thing with a superlative._
