## transform (15)

1. _Rewrite the sentence with might._  
   It's possible that it will rain this **evening**, **Timur**.  
   → It ______ rain this **evening**, **Timur**.  
   key: might  
   why: It's possible that … will = might.

2. _Rewrite the sentence with might._  
   It's possible that the **plane** will be late, **Olga**.  
   → The **plane** ______ be late, **Olga**.  
   key: might  
   why: It's possible that … will = might.

3. _Rewrite the sentence with might._  
   Perhaps **Lola** will come to the **party**.  
   → **Lola** ______ come to the **party**.  
   key: might  
   why: Perhaps … will = might.

4. _Rewrite the sentence with might._  
   Maybe we will go to **Bukhara** next **spring**.  
   → We ______ go to **Bukhara** next **spring**.  
   key: might  
   why: Maybe … will = might.

5. _Rewrite the sentence with might._  
   It's possible that the **museum** is closed today, **Aziz**.  
   → The **museum** ______ be closed today, **Aziz**.  
   key: might  
   why: It's possible that … is = might be.

6. _Rewrite the sentence with might not._

11. _Correct the mistake._  
   **Aziz** might comes to the **concert**.

13. _Correct the mistake._

   → We ______ **Fergana** next **year**.

   why: No to after might: might visit.

14. _Correct the mistake._  
   The **tram** mights be late, **Aziz**.  
   → The **tram** ______ be late, **Aziz**.  
   key: might  
   why: Might never takes -s: he might, it might.

   key: might not  
   why: No to after might not: might not like.
