## transform (15)

1. _Say the same thing with so. Start with the reason._  
   We stayed at home **last night** because it was raining.  
   → It was raining **last night**, ______ (stay) at home.  
   key: so we stayed  
   why: Because gives the reason; so gives the result. Reason first, then so + result.

2. _Say the same thing with so. Start with the reason._  
   Lola went to bed early because she was **very tired**.  
   → Lola was **very tired**, ______ (go) to bed early.  
   key: so she went  
   why: Reason first (she was tired), then so + result: so she went…

3. _Say the same thing with so. Start with the reason._  
   The children played inside **all day** because it was **too hot**.  
   → It was **too hot** **all day**, ______ (play) inside.  
   key: so the children played (also: so they played)  
   why: Reason first, then so + result: so the children played inside.

4. _Say the same thing with so. Start with the reason._  
   Aziz bought a new phone **on Friday** because his old one was **too old**.  
   → Aziz's old phone was **too old**, ______ (buy) a new one **on Friday**.  
   key: so he bought  
   why: Reason first, then so + result: so he bought a new one.

5. _Say the same thing with so. Start with the reason._  
   Dad took a taxi **yesterday** because he was **late**.  
   → Dad was **late**, ______ (take) a taxi **yesterday**.  
   key: so he took  
   why: Reason first, then so + result: so he took a taxi.

6. _Join the two sentences with so. Use the verb in brackets._  
   Aziz was late **today**. He ran to **school**.  
   → Aziz was late **today**, ______ (run) to **school**.  
   key: so he ran  
   why: The second sentence is the result, so join with so: so he ran.

7. _Join the two sentences with so. Use the verb in brackets._  
   The **bakery** was closed. We went home **again**.  
   → The **bakery** was closed, ______ (go) home **again**.  
   key: so we went  
   why: The second sentence is the result: so we went home.

8. _Join the two sentences with so. Use the verb in brackets._  
   Malika was thirsty after **lunch**. She drank some **juice**.  
   → Malika was thirsty after **lunch**, ______ (drink) some **juice**.  
   key: so she drank  
   why: The second sentence is the result: so she drank…

9. _Join the two sentences with so. Use the verb in brackets._  
   It was my brother's birthday. We made a **special dinner** **together**.  
   → It was my brother's birthday, ______ (make) a **special dinner** **together**.  
   key: so we made  
   why: The second sentence is the result: so we made…

10. _Join the two sentences with so. Use the verb in brackets._  
   The film was **too long**. My friends left **before the end**.  
   → The film was **too long**, ______ (leave) **before the end**.  
   key: so my friends left (also: so they left)  
   why: The second sentence is the result: so my friends left.

11. _Rewrite with so instead of That's why._  
   The **taxi** didn't come. That's why we walked **home**.  
   → The **taxi** didn't come, ______ (walk) **home**.  
   key: so we walked  
   why: That's why = so: so we walked…

12. _Rewrite with so instead of That's why._  
   Bobur is ill. That's why he isn't at **the party** **this week**.  
   → Bobur is ill, ______ (be) at **the party** **this week**.  
   key: so he isn't  
   why: That's why = so: so he isn't at school.

13. _Rewrite with so instead of That's why._  
   Our **doctor** is very kind. That's why everyone loves her, **Mum**.  
   → Our **doctor** is very kind, ______ (love) her, **Mum**.  
   key: so everyone loves  
   why: That's why = so: so everyone loves her.

14. _Rewrite with so instead of That's why._
