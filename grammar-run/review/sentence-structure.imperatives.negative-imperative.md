## transform (15)

1. _Correct the mistake._  
   No touch the **pan**, **Aziz**. It's hot.  
   → ______ the **pan**, **Aziz**. It's hot.  
   key: don't touch  
   why: A negative order starts with Don't, not No: Don't touch.

2. _Correct the mistake._  
   Don't running on the **wet floor**, **boys**.  
   → ______ on the **wet floor**, **boys**.  
   key: don't run  
   why: After Don't, use the base verb, with no -ing: Don't run.

3. _Correct the mistake._  
   Don't late for **school**, **Olga**.  
   → ______ late for **school**, **Olga**.  
   key: don't be  
   why: Late is an adjective, so the order needs be: Don't be late.

4. _Correct the mistake._  
   Doesn't eat that **meat**, **Timur**. It's old.  
   → ______ that **meat**, **Timur**. It's old.  
   key: don't eat  
   why: An order always uses Don't, never Doesn't: Don't eat.

5. _Correct the mistake._  
   Don't to forget your **ticket**, **Lola**.
