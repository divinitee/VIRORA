## create (8)

1. Write a question to ask a new friend about a sport they can play.  
   must use: Can you + base verb … ? · exactly one question · must start with Can you · must name a sport

2. Write a question about a language someone in your class can speak.  
   must use: Can he / she speak … ? · exactly one question · must name the person · can before the person

3. Write a question with What can … ? about cooking.  
   must use: What can + subject + cook? · exactly one question · must start with What can · must end with a question mark

4. Write a question with Where can … ? about buying something in your city.  
   must use: Where can I / we buy … ? · exactly one question · must start with Where can · must name a thing to buy

5. Write a question to ask your teacher about something your class can do.  
   must use: Can we + base verb … ? · exactly one question · must use Can we · no to after can

6. Write a question about an animal and what it can do.  
   must use: Can + animal + base verb? · exactly one question · must name an animal · can before the animal

7. Write a question with How many … can … ?  
   must use: How many + noun + can + subject + verb? · exactly one question · must start with How many · can before the subject

8. Write two questions to ask a friend about their skills.  
   must use: Can you + base verb … ? · exactly two questions · two different verbs · no do or does with can

## express (5)

1. You are interviewing a new member for your school club. Write four questions with can.  
   target: yes/no and wh- questions with can · look for: Can you + base verb? · a wh- question with can · no Do you can…?

2. Write a short dialogue: you meet an exchange student. Ask what they can do and answer their questions about you.  
   target: can questions and short answers · look for: Can you … ? · Yes, I can / No, I can't · can before the subject

3. You want to rent a flat. Write four questions to the owner with can (pets, guests, parking, internet).  
   target: Can I / Can we + base verb … ? · look for: Can I / Can we · base verb after can · a question mark on each question

4. Write questions for a class survey about skills: cooking, languages, sports and music.  
   target: Can you + base verb … ? / How many … can you … ? · look for: four or more questions · a How many / How well question · no to after can

5. A tourist asks you about your city. Write four questions they could ask with Where can … ? or What can … ?  
   target: wh- questions with can · look for: Where can I / we … · What can I / we … · can before the subject
